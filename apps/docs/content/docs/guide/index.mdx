description: Learn the Crust command-authoring model.
---

Build an application in layers:

1. Define [commands](/docs/guide/commands), [arguments](/docs/guide/arguments), and [flags](/docs/guide/flags) with their [value types](/docs/guide/types).
2. Compose [subcommands](/docs/guide/subcommands) inline or [split them across files](/docs/guide/split-files).
3. Add app-wide [Extensions](/docs/guide/extensions) and command dependencies with [Contexts](/docs/guide/contexts).
4. Understand the [execution model](/docs/guide/lifecycle) and [error handling](/docs/guide/error-handling).
5. Set up [environment variables](/docs/guide/environment) and [local development](/docs/guide/development), then [test the application](/docs/guide/testing).
6. Choose a [runtime](/docs/guide/runtimes), then [build and distribute](/docs/guide/build) the application.
