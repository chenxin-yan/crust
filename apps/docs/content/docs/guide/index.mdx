Build an application in layers:

1. **Define:** [commands and subcommands](/docs/guide/commands), [arguments](/docs/guide/arguments), [flags](/docs/guide/flags), and [values and validation](/docs/guide/types).
2. **Compose:** [Contexts](/docs/guide/contexts) and [Extensions](/docs/guide/extensions).
3. **Run:** [execution lifecycle](/docs/guide/lifecycle), [error handling](/docs/guide/error-handling), and [testing](/docs/guide/testing).
4. **Ship:** [runtime support](/docs/guide/runtimes), [environment variables](/docs/guide/environment), and [build and distribution](/docs/guide/build).
