Build an application in layers:

1. Define [commands](/docs/guide/commands), [arguments](/docs/guide/arguments), and [flags](/docs/guide/flags).
2. Compose [subcommands](/docs/guide/subcommands) inline or [split them across files](/docs/guide/split-files).
3. Add app-wide [Extensions](/docs/guide/extensions) and command dependencies with [Contexts](/docs/guide/contexts).
4. Understand the [execution model](/docs/guide/lifecycle) and [error handling](/docs/guide/error-handling).
5. [Build and distribute](/docs/guide/build) the application.
