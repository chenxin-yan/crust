Extensions add CLI capabilities such as help, completion, rendering, did-you-mean suggestions, update notifications, and generated internal commands.

## Extensions

Use extensions when you want to change the CLI system itself:

```ts
import { Crust } from "@crustjs/core";
import { completion, didYouMean, help, version } from "@crustjs/plugins";

const app = new Crust("my-cli")
  .meta({ description: "My CLI" })
  .extend(version("1.0.0"), didYouMean({ mode: "help" }), help(), completion())
  .run(() => {
    console.log("Running!");
  });

await app.execute();
```

Official extensions include:

| Extension                                                   | Description                                                 |
| ----------------------------------------------------------- | ----------------------------------------------------------- |
| [`help()`](/docs/modules/plugins/help)                      | Adds `--help` / `-h` and auto-generates help text           |
| [`version()`](/docs/modules/plugins/version)                | Adds `--version` / `-v` to the root command                 |
| [`didYouMean()`](/docs/modules/plugins/did-you-mean)        | Suggests corrections for mistyped subcommands               |
| [`updateNotifier()`](/docs/modules/plugins/update-notifier) | Checks npm for newer versions and displays an update notice |
| [`completion()`](/docs/modules/plugins/completion)          | Generates bash/zsh/fish tab-completion scripts              |

Extensions can contribute flags or hidden commands, install renderers or error formatters, wrap/observe execution, and contribute metadata for completion, man pages, or skills.

## Authoring Extensions

Use `extension(name)` to author reusable CLI capabilities:

```ts
import { extension } from "@crustjs/core";

const timing = extension("timing").wrapRun((run) => async (ctx) => {
  const startedAt = performance.now();
  try {
    return await run(ctx);
  } finally {
    console.error(`Done in ${performance.now() - startedAt}ms`);
  }
});

const app = new Crust("my-cli").extend(timing);
```

Extensions can contribute flags, contribute internal commands, wrap command execution, and install error handling or rendering behavior. Extension internals are intentionally hidden from command handlers.
