title: Arguments
description: Define typed positional inputs for a command.

import { Callout } from "fumadocs-ui/components/callout";

Arguments map positional tokens to names in definition order.

```ts
const command = new Crust("serve")
  .args([
    { name: "port", type: "number", default: 3000 },
    { name: "host", type: "string", default: "localhost" },
  ])
  .handle(({ args, stdout }) => stdout(`${args.host}:${args.port}`));
```

## Required, optional, and defaulted

```ts
.args([
  { name: "input", type: "path", required: true },
  { name: "format", type: "string", default: "json" },
  { name: "label", type: "string" },
])
```

The inferred types are `string`, `string`, and `string | undefined`, respectively. See [`ArgDef`](/docs/api/types#argdef) for all properties.

## Variadic arguments

Only the final argument can be variadic:

```ts
new Crust("copy")
  .args([
    { name: "destination", type: "path", required: true },
    { name: "files", type: "path", variadic: true },
  ])
  .handle(({ args }) => {
    args.files; // string[]
  });
```

A variadic value is always an array. `required: true` rejects an empty array.

## Choices

Use `choices` for a static string set:

```ts
.args([{ name: "target", type: "string", choices: ["bun", "node"] }] as const)
```

Invalid choices produce a `PARSE` error.

## Standard Schemas

A `schema` receives the raw positional token (`string | undefined`, or `string[]` for a variadic argument) and determines the Command Handler's output type:

```ts
import { z } from "zod";

new Crust("serve")
  .args([{ name: "port", schema: z.coerce.number().int().positive() }] as const)
  .handle(({ args }) => {
    args.port; // number
  });
```

<Callout type="warn">
  Schema-backed arguments cannot also use core value options such as `type`, `default`, `required`,
  `choices`, or `parse`. The schema owns coercion, defaults, requiredness, choices, and validation.
</Callout>

See [Schema-backed definitions](/docs/guide/types#schema-backed-definitions).

## Forwarding raw tokens

Tokens after `--` bypass argument and flag parsing and appear in `rawArgs`:

```ts
new Crust("wrap").handle(({ rawArgs, stdout }) => stdout(rawArgs.join(" ")));
```
