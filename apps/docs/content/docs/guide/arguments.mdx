title: Arguments
description: Define typed positional inputs for a command.
---

`.args(...defs)` maps positional tokens to names in definition order. Repeated calls append in call order, and duplicate names fail typecheck with `FIX_DUPLICATE_ARG`.

<include lang="ts">../../../examples/guide/arguments.ts#definitions</include>

Pass definitions from `defineArg(name, def)` or use inline literals as above.

## Required, optional, and defaulted

<include lang="ts">../../../examples/guide/arguments.ts#defaults</include>

`input` is required, `format` resolves to its default when omitted, and `label` remains optional. Their inferred types are `string`, `string`, and `string | undefined`; see [`ArgDef`](/docs/api/types#argdef) for all properties.

## Variadic arguments

```ts
const copy = new Crust("copy")
  .args(
    { name: "destination", type: "path", required: true },
    { name: "files", type: "path", variadic: true },
  )
  .action(({ args }) => args.files); // string[]
```

Only the final argument can be variadic, and its Command Action value is an array. See [structured invocation](/docs/api/crust#runpath-input-io) for required variadics and typed `run()` input.

## Choices

<include lang="ts">../../../examples/guide/arguments.ts#choices</include>

Use `choices` for a static string set. An invalid supplied choice produces a `PARSE` failure, while a literal choices tuple narrows the inferred value to its string union.

## Standard Schemas

```ts
import { z } from "zod";

new Crust("serve")
  .args({ name: "port", schema: z.coerce.number().int().positive() })
  .action(({ args }) => console.log(args.port)); // number
```

See [Schema-backed definitions](/docs/guide/types#schema-backed-definitions) for schema input, output, and definition rules.

## Excess and raw tokens

```sh
$ bun run cli.ts first second
Error: Unexpected positional argument: "second"
$ echo $?
1
```

Positionals before `--` must match a declared argument. Excess values fail with `VALIDATION`; use a variadic argument for an open-ended list.

<include lang="ts">../../../examples/guide/arguments.ts#raw</include>

Tokens after `--` bypass argument and flag parsing and appear in `rawArgs`. The `raw` field provides the same values to `run()`.
