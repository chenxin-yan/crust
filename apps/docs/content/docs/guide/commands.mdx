A Crust value is an immutable command tree; compose it, then call `execute()` once at the entrypoint.

<include lang="ts" meta='title="src/cli.ts"'>../../../examples/guide/hello.ts</include>

```sh
$ bun src/cli.ts
Hello!
```

## Grow in one file

<include lang="ts" meta='title="src/cli.ts"'>../../../examples/guide/commands.ts</include>

```sh
$ tool build --minify
minify: true
```

Use `.command()` for a short, app-local leaf command. Each builder call returns a new `Crust` value, so keep the returned value.

When a command needs its own file or reuse, move it to a definition created with `defineCommand()` and attach it with `.add()`.

## Unknown commands

```sh
$ tool deploy
Error: Unknown command "deploy".
$ echo $?
1
```

A token that matches no subcommand is an unknown command when the current command has no Command Action; with an action, it is parsed as a positional argument. See the [`run()` routing contract](/docs/api/crust#runpath-input-io) for programmatic paths and error details.

## Split across files

```text
src/
├── commands/greet.ts
├── app.ts
└── cli.ts
```

Use this shape once commands need separate files. Command modules export definitions, `app.ts` owns the root, and only `cli.ts` executes the completed tree.
