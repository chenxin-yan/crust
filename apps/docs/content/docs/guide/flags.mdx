```ts
const command = new Crust("serve")
  .flags({
    port: { type: "number", default: 3000, short: "p" },
    verbose: { type: "boolean", short: "v" },
  })
  .handle(({ flags, stdout }) => stdout(`${flags.port} ${flags.verbose ?? false}`));
```

See [`FlagDef`](/docs/api/types#flagdef) for the complete definition.

## Aliases and negation

`short` defines one single-character form. `aliases` adds other short or long forms:

```ts
.flags({ output: { type: "path", short: "o", aliases: ["out"] } })
```

Boolean flags support canonical `--no-name` negation. They do not accept `--name=true`. Flag names, short forms, and aliases must be unique, and the `no-` prefix is reserved; violations are `DEFINITION` errors.

## Required and defaulted values

```ts
.flags({
  token: { type: "string", required: true },
  format: { type: "string", default: "json" },
})
```

Both values are non-optional in the Command Handler. Other flags include `undefined` in their inferred type.

## Repeated values

```ts
.flags({ target: { type: "string", multiple: true, short: "t" } })
```

`--target linux --target darwin` produces `string[]`. Repeated boolean flags also collect booleans when `multiple: true`.

## Choices

```ts
.flags({ target: { type: "string", choices: ["bun", "node"] } })
```

Choices are supported on string flags and invalid values produce `PARSE` errors.

## Inherited flags

Set `inherit: true` to expose a parent flag to descendant Command Handlers:

```ts
const app = new Crust("app")
  .flags({ verbose: { type: "boolean", inherit: true } })
  .command("deploy", (command) =>
    command.flags({ env: { type: "string", required: true } }).handle(({ flags }) => {
      flags.verbose; // boolean | undefined
      flags.env; // string
    }),
  );
```

The flag is parsed and shown in help at each descendant.

Reusable definitions declare inherited flag requirements explicitly:

```ts
import { Crust, defineCommand, defineFlag } from "@crustjs/core";

const verbose = defineFlag({ type: "boolean", inherit: true });

const deploy = defineCommand<{
  flags: { verbose: typeof verbose };
}>()((command) => command.handle(({ flags }) => flags.verbose));

const app = new Crust("app").flags({ verbose }).mount("deploy", deploy);
```

`.mount()` checks the parent's current builder. Define required flags with `inherit: true` before mounting. A same-named non-inheritable flag is treated as missing, and incompatible inferred value types are rejected. Flags added on a later builder do not backfill an earlier mount.

## Standard Schemas

For a schema-backed flag, `type` controls token grammar only: `"string"` consumes a token and `"boolean"` does not. The schema owns the resulting value.

```ts
import { z } from "zod";

new Crust("serve")
  .flags({ port: { type: "string", schema: z.coerce.number().int() } })
  .handle(({ flags }) => {
    flags.port; // number
  });
```

<Callout type="warn">
  Do not combine `schema` with core value options such as `default`, `required`, `choices`, or
  `parse`.
</Callout>
