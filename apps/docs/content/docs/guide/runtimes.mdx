---
title: Runtime support
description: Run Crust applications with Bun, Node.js, or Deno.
---

Crust application code is the same on Bun, Node.js, and Deno, so pick a runtime based on how you ship and operate the CLI.

## Supported runtimes

```sh tab="Bun"
bun add @crustjs/core
```

```sh tab="Node.js"
npm install @crustjs/core
```

```sh tab="Deno"
deno add npm:@crustjs/core
```

The Crust packages support Bun 1.3.14+, Node.js 22+, and Deno 2.8+. [`@crustjs/tui`](/docs/modules/tui) is Bun only because its OpenTUI peer is a native library, while the `crust` build CLI is Bun tooling distributed through a Node launcher.

## Deno permissions

```sh
deno run --allow-run=git --allow-read=. --allow-write=./dist --allow-env ./src/cli.ts
```

Deno applies its permission sandbox to library code. See [Deno permissions](https://docs.deno.com/runtime/fundamentals/security/) for the runtime rules and flag syntax.
