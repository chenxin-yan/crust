A Context is a named dependency that is constructed on first access and memoized for one invocation.

<include lang="ts">../../../examples/guide/contexts.ts#lazy</include>

The action never reads `ctx.cache`, so the setup log is absent.

## Owned flags

<include lang="ts">../../../examples/guide/contexts.ts#owned-flags</include>

`.provide()` installs a Context's flags on the provider command and descendants added later. Setup receives its validated owned flag values, whether terminal syntax puts them before or after the subcommand. A `preRun` hook cannot access a Context that owns flags, directly or transitively; see [`ExtensionHooks`](/docs/api/types#extensionhooks).

## Context dependencies

<include lang="ts">../../../examples/guide/contexts.ts#dependencies</include>

Declare setup dependencies with `uses`, then await them through the setup's typed `ctx` bag. Dependencies stay lazy until read.

## Contexts in command trees

<include lang="ts">../../../examples/guide/contexts.ts#command-trees</include>

A reusable definition declares demand with `.use(factory)`, while the app supplies an instance with `.provide(factory())`. Add the definition after its provider is available on that command path.

## Dynamic definitions and attachment

<include lang="ts">../../../examples/guide/contexts.ts#dynamic</include>

Use `defineContext(name, config, setup)` when names or configuration come from runtime values. `.provide()` and `.add()` check the resulting definitions when they attach to a destination.

## Test doubles

<include lang="ts">../../../examples/guide/contexts.ts#doubles</include>

`.of(value)` supplies a precomputed value with the same Context name and value type. Its setup has no dependencies, while its owned flags remain attached.

## Cleanup

<include lang="ts">../../../examples/guide/contexts.ts#cleanup</include>

Return `Symbol.dispose` or `Symbol.asyncDispose` on constructed values. Cleanup runs after post-run hooks in reverse construction order, on both success and failure.

## Collisions

<include lang="ts">../../../examples/guide/contexts.ts#collisions</include>

Dynamically assembled owned-flag collisions throw `CrustError` with code `DEFINITION`. See [`.provide()`](/docs/api/crust#provideinstances) for the complete attachment and collision contract.
