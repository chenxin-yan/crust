`@crustjs/testing` runs a Crust application with captured output or fake terminal streams. It is for application developers; install it alongside `@crustjs/core`.

```sh
bun add -d @crustjs/testing
```

## Capture command output

Use `captureRun()` for commands that write ordinary stdout or stderr or return a value. Each `ctx.stdout()`/`ctx.stderr()` call is captured as one line, joined with `"\n"` (matching the terminal defaults). The capture is a status-discriminated union: `completed` carries the action's inferred `result`, `finished` names the Extension whose `preRun` hook ended the invocation, and `failed` carries the thrown value without discarding earlier output.

```ts
import { expect, test } from "bun:test";
import { captureRun } from "@crustjs/testing";

import { app } from "./cli.ts";

test("greets a name", async () => {
  const captured = await captureRun(app, [], { args: { name: "Ada" } });

  expect(captured.stdout).toBe("Hello, Ada!");
  expect(captured.stderr).toBe("");
  expect(captured.status).toBe("completed");
});
```

## Capture terminal execution

Use `captureExecute()` to exercise the terminal `execute()` path, including Extension error rendering and the exit code established through `process.exitCode`. It captures stdout and stderr, restores the previous process exit code afterward, and reports cancellation as exit code `130`.

```ts
import { expect, test } from "bun:test";
import { captureExecute } from "@crustjs/testing";

import { app } from "./cli.ts";

test("renders invalid input", async () => {
  const result = await captureExecute(app, ["--unknown"]);

  expect(result.stdout).toBe("");
  expect(result.stderr).toContain("Unknown flag");
  expect(result.exitCode).toBe(1);
});
```

## Fake a Context

Every `defineContext()` factory carries `.of(value)`, which produces an instance returning the precomputed value without running setup. Provide it in place of the real Context when composing an application for a test:

```ts
import { Crust } from "@crustjs/core";
import { database } from "./contexts.ts";

const app = new Crust("my-cli")
  .provide(database.of({ query: (sql) => `fake: ${sql}` }))
  .action(async ({ ctx, stdout }) => stdout((await ctx.database).query("select 1")));
```

See [Contexts](/docs/guide/contexts#test-doubles).

## Test interactive commands

Use `runInteractive()` when an action renders a built-in prompt. Its `type()` and `keys()` methods send terminal input. Prompt frames and `ctx.stderr()` text share one stderr transcript, so `waitFor()` and `screen()` observe the same terminal output.

```ts
import { expect, test } from "bun:test";
import { runInteractive } from "@crustjs/testing";

import { app } from "./cli.ts";

test("collects a name", async () => {
  const run = runInteractive(app, []);
  await run.waitFor(/Name\?/);

  run.type("Ada");
  run.keys("return");
  await run.done;

  expect(run.screen()).toContain("Hello, Ada!");
});
```

`done` rejects with the original application error, matching `app.run()`. `waitFor()` never hangs on a failed or finished run: it rethrows the application error, or throws with the current screen when the pattern can no longer match or its timeout (default 5000ms) elapses.

Use `captureExecute(app, argv)` for raw parser behavior such as short-flag bundles, `--flag=value`, and invalid spellings. Statically declared `defineExtension()` commands appear in the typed `captureRun()` and `runInteractive()` paths; use `captureExecute()` for dynamically assembled or type-widened Extension contributions.

## For custom prompt authors

<Callout type="warn" title="Built-in prompts are already covered">
  You do not test built-in prompts. The library covers them. Use this only when authoring a custom
  `(options, io?)` prompt.
</Callout>

Use `@crustjs/prompts/testing` directly for custom prompt functions:

```ts
import { expect, test } from "bun:test";
import { renderPrompt } from "@crustjs/prompts/testing";

import { myPrompt } from "./my-prompt.ts";

test("collects a name", async () => {
  const prompt = renderPrompt(myPrompt, { message: "Name?" });
  prompt.type("Ada");
  prompt.keys("return");

  expect(await prompt.answer).toBe("Ada");
});
```
