title: Crust

---

Crust defines typed command-line applications with immutable builders and runs them on Bun.

## Define a command

```ts
import { Crust } from "@crustjs/core";
import { help, version } from "@crustjs/extensions";

const app = new Crust("hello")
  .meta({ description: "Print a greeting" })
  .extend(version("0.2.0"), help())
  .args([{ name: "name", type: "string", default: "world" }])
  .flags({ loud: { type: "boolean", short: "l" } })
  .handle(({ args, flags, stdout }) => {
    const greeting = `Hello, ${args.name}!`;
    stdout(flags.loud ? greeting.toUpperCase() : greeting);
  });

await app.execute();
```

## Core concepts

- **Immutable builders** — `.meta()`, `.args()`, `.flags()`, `.command()`, and `.handle()` return new builders with inferred input types.
- **Extensions** — app-wide capabilities attached once at the root with `.extend()`. Official Extensions provide help, version, completion, suggestions, color control, and update notices.
- **Contexts** — named command dependencies created lazily for the resolved command path and attached with `.provide()`.
- **Schema-first validation** — place any Standard Schema on an argument or flag definition; the Command Handler receives its output type.
- **Two invocation modes** — `.execute()` owns terminal error presentation and exit status; `.run(argv, io)` is programmatic and throws the original error.
