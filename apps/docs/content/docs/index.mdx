## What is Crust?

Crust is **a TypeScript CLI framework with composable modules for humans and agents**. It runs on Bun, Node.js, and Deno, and uses Bun's native APIs where they exist.

## Why Crust?

A minimal argument parser gives you flexibility, but leaves you to assemble the rest of your CLI. A batteries-included framework provides more structure, but can bring conventions and features you don't need. Crust aims for the sweet spot: a typed command model with parsing and routing built in, plus optional modules you add as your CLI grows.

Define a command once: its arguments and flags drive parsing and type inference, while modules generate help, shell completion, manual pages, and agent skills from the same definitions. You don't maintain a separate description of your CLI for each audience.

The core has no runtime package dependencies. Standalone libraries such as styling and prompts also work without the framework.

## Capabilities

- **Commands and input parsing.** Nested [commands](/docs/guide/commands), [arguments and flags](/docs/guide/arguments-and-flags) with aliases, defaults, choices, [Standard Schema validation](/docs/guide/values-and-validation#schema-backed-definitions), and inferred types.
- **[Extensions](/docs/guide/extensions).** Shared flags, commands, lifecycle hooks, and build hooks, plus [official extensions](/docs/modules/extensions) for help, version, typo suggestions, and update notices.
- **[Dependency injection](/docs/guide/contexts).** Typed Contexts with lazy initialization and automatic cleanup.
- **Generated from your definitions.** [Shell completion](/docs/modules/extensions/completion) for Bash, Zsh, and Fish, [manual pages](/docs/modules/man), and [agent skills](/docs/modules/skills).
- **Terminal UI.** [Styling](/docs/modules/style), [interactive prompts](/docs/modules/prompts), and [progress indicators](/docs/modules/progress). Progress supports non-interactive output; prompts can use explicit defaults, except for passwords, or reject when interaction is required. Build [full-screen apps](/docs/modules/tui) through OpenTUI (Bun only).
- **[Testing helpers](/docs/guide/testing).** Capture output and exit codes, or drive interactive commands with simulated input.
- **[Build and distribution](/docs/guide/build-and-distribution).** Standalone Bun or Deno executables, or a Node.js bundle.
