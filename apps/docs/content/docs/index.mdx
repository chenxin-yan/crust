## What is Crust?

Crust is **a TypeScript CLI framework with composable modules for humans and agents**. It runs on Bun, Node.js, and Deno, and uses Bun's native APIs where they exist.

## Why Crust?

A minimal argument parser gives you flexibility, but leaves you to assemble the rest of your CLI. A batteries-included framework provides more structure, but can bring conventions and features you don't need. Crust aims for the sweet spot: a typed command model with parsing and routing built in, plus optional modules you add as your CLI grows.

Define a command once: its arguments and flags drive parsing and type inference, while modules generate help, shell completion, manual pages, and agent skills from the same definitions. You don't maintain a separate description of your CLI for each audience.

The core has no third-party runtime dependencies. Standalone libraries such as styling and prompts also work without the framework.

## Capabilities

- **Typed commands.** Define nested [commands](/docs/guide/commands), [arguments and flags](/docs/guide/arguments-and-flags) with inferred types and [schema validation](/docs/guide/values-and-validation#schema-backed-definitions).
- **[Extensions](/docs/guide/extensions).** Add help, version information, [completion](/docs/modules/extensions/completion), and shared behavior.
- **[Shared resources](/docs/guide/contexts).** Provide typed dependencies with lazy initialization and automatic cleanup.
- **Generated documentation.** Turn command definitions into [manual pages](/docs/modules/man) and [agent skills](/docs/modules/skills).
- **Terminal UI.** Add [styling](/docs/modules/style), [prompts](/docs/modules/prompts), [progress indicators](/docs/modules/progress), and [full-screen apps](/docs/modules/tui) (Bun only).
- **[Testing](/docs/guide/testing).** Capture output and exit codes, or simulate interactive input.
- **[Distribution](/docs/guide/build-and-distribution).** Build standalone Bun or Deno executables, or a Node.js bundle.
