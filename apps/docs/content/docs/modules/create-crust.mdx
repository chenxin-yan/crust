title: "create-crust"
description: Scaffold a new Crust CLI project interactively.
---

`create-crust` generates a minimal Crust application and configures it for standalone binary or Bun runtime distribution.

## Usage

Run it through your runtime's package runner or create command:

```sh
npm create crust@latest my-cli
# or
pnpm create crust@latest my-cli
# or
bunx create-crust@latest my-cli
# or
bun create crust@latest my-cli
# or
deno run -A npm:create-crust@latest my-cli
```

The optional directory argument sets the destination. Without it, the CLI prompts for a directory and defaults to `my-cli`.

## Prompt behavior

Flags set initial prompt answers rather than skipping prompts. For example, start with Bun runtime distribution selected and dependency installation declined:

```sh
bunx create-crust@latest my-cli --distribution runtime --no-install
```

The prompt defaults and behavior are:

- `--distribution`: Preselect the distribution prompt. The default is `binary` (standalone executables); `runtime` produces a package that runs with Bun.
- `--install` / `--no-install`: Set the initial answer to the dependency-installation prompt. The default is to install dependencies.
- `--git` / `--no-git`: Set the initial answer to the Git initialization prompt. The default is to initialize; no repository is created when the destination is in a repo.
- `--overwrite` / `--no-overwrite`: Set the initial answer when confirming an existing destination. The default is not to overwrite. Confirmation is still required.

The CLI collects every prompt before writing files, then scaffolds the project and optionally installs dependencies and initializes Git. The package name is inferred from the destination directory.

For the complete option definitions, see the [create-crust command source](https://github.com/chenxin-yan/crust/blob/main/packages/create-crust/src/index.ts), which tracks `main`.

Generated projects use the single-file `src/cli.ts` starter. See [Build and distribution](/docs/guide/build) for standalone and runtime packaging workflows.
