title: "Man"
description: Generate mdoc(7) manual pages from Crust Command Snapshots.

`@crustjs/man` generates section 1 manual pages at build or publish time.

## Install

```sh
bun add -d @crustjs/man
```

Peer dependency: `@crustjs/core`.

## `writeManPage(options)`

```ts
function writeManPage(options: WriteManPageOptions): Promise<void>;
```

<auto-type-table
  path="../../../../../packages/man/src/write-man-page.ts"
  name="WriteManPageOptions"
/>

`writeManPage` prepares and validates the application's final Command Snapshot, renders mdoc, creates parent directories, and writes the page.

```ts
import { writeManPage } from "@crustjs/man";
import { app } from "./cli.ts";

await writeManPage({
  app,
  name: "my-cli",
  outfile: "man/my-cli.1",
  section: 1,
});
```

`section` defaults to `1`. `date` overrides the `.Dd` value. Without `date`, rendering uses `SOURCE_DATE_EPOCH` in UTC when set, then falls back to the current local date. Generated dates use the English `Month D, YYYY` form expected by mdoc.

## `renderManPageMdoc(options)`

```ts
function renderManPageMdoc(options: RenderManPageMdocOptions): string;
```

<auto-type-table
  path="../../../../../packages/man/src/mdoc.ts"
  name="RenderManPageMdocOptions"
/>

Use this lower-level function when you already have a frozen Command Snapshot. It does not accept a live command definition.

```ts
import { renderManPageMdoc } from "@crustjs/man";

const source = renderManPageMdoc({
  root: snapshot,
  name: "my-cli",
});
```

The renderer uses semantic mdoc(7) flag and argument macros. It intentionally summarizes only the root command's immediate visible subcommands; nested commands remain available in the shared full-tree documentation model.

The package prepares the command tree through the supported `app.snapshot()` method. It uses `buildCommandDocumentation()` from `@crustjs/core/tooling` internally for its lockstep first-party rendering model.

## Package script

```json
{
  "scripts": {
    "generate:man": "bun run scripts/generate-man.ts"
  },
  "files": ["dist", "man"],
  "man": ["./man/my-cli.1"]
}
```

Preview and lint locally:

```sh
bun run generate:man
man -l man/my-cli.1
mandoc -T lint -W warning man/my-cli.1
```

## `crust build --man`

[`crust build --man`](/docs/modules/crust) generates the same page while building. The entry module must export the root builder as `app` or as its default export. With `--package --man`, the staged root npm package includes the generated page and npm `man` metadata.
