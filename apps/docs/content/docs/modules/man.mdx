---
title: "Man"
description: Generate mdoc(7) manual pages from Crust Command Snapshots.
---

`@crustjs/man` generates manual pages at build time. `crust publish` only reads and publishes output already staged by a package build.

## Install

```sh
bun add -d @crustjs/man
```

The package has a peer dependency on `@crustjs/core`.

## `man(options?)`

```ts
import { Crust } from "@crustjs/core";
import { man } from "@crustjs/man";

const app = new Crust("my-cli").extend(man());
```

```text
dist/man/my-cli.1
```

`man()` registers a build hook that writes `man/<name>.<section>` under the build output directory. It reports that relative path as a build artifact owned by `crust:man`.

```text
.Dd March 1, 2026
.Dt MY_CLI 1
.Os
.Sh NAME
.Nm my-cli
```

Pass `man({ section: 5 })` to change the section and filename, or `man({ name: "my-tool" })` when the installed command name differs from the application name. The `man.id` static exposes the Extension identity used for section filtering.

## `writeManPage(options)`

```ts
import { writeManPage } from "@crustjs/man";

const root = await app.snapshot();
await writeManPage({ root, name: "my-cli", outfile: "man/my-cli.1" });
// Writes man/my-cli.1
```

<auto-type-table
  path="../../../../../packages/man/src/write-man-page.ts"
  name="WriteManPageOptions"
/>

`writeManPage()` renders a Command Snapshot, creates parent directories, and writes the page. `section` defaults to `1`; `date` overrides the `.Dd` value.

Without `date`, rendering uses `SOURCE_DATE_EPOCH` in UTC when set, then the current local date. Generated dates use the English `Month D, YYYY` form expected by mdoc.

## `renderManPageMdoc(options)`

```ts
import { renderManPageMdoc } from "@crustjs/man";

const root = await app.snapshot();
const source = renderManPageMdoc({ root, name: "my-cli" });
console.log(source.startsWith(".Dd ")); // => true
```

<auto-type-table
  path="../../../../../packages/man/src/mdoc.ts"
  name="RenderManPageMdocOptions"
/>

`renderManPageMdoc()` returns mdoc text without writing a file. It accepts a prepared Command Snapshot, not a live definition.

The renderer lists immediate visible children in the root summary and collects visible subcommand sections under `.Sh COMMANDS`. Sections targeted to `man` are audience-filtered, and same-title sections merge at their first position.

```ts
new Crust("my-cli", {
  sections: [{ title: "FILES", body: "~/.config/my-cli.json", only: [man] }],
});
```

Use `only: [man]` to include a section only in manual pages, or `except: [man]` to omit it there.

## Package script

```json
{
  "scripts": { "generate:man": "bun run scripts/generate-man.ts" },
  "files": ["dist", "man"],
  "man": ["./man/my-cli.1"]
}
```

```sh
bun run generate:man
man -l man/my-cli.1
mandoc -T lint -W warning man/my-cli.1
```

Use `writeManPage()` for a custom pipeline outside the Extension build lifecycle.
