---
title: "No Color"
description: Add `--color` and `--no-color` to a Crust CLI.
---

The `noColor()` extension adds a root `color` boolean flag with default `true`, exposing `--color` and `--no-color`.

It is designed to align with [no-color.org](https://no-color.org/):

- `NO_COLOR=1` disables color by default
- `NO_COLOR=""` does not disable color
- `--color` overrides `NO_COLOR`
- `--no-color` disables color for the current run
- Non-color modifiers such as bold and underline are not disabled

## Usage

```ts
import { Crust } from "@crustjs/core";
import { help, noColor, version } from "@crustjs/plugins";

const app = new Crust("my-cli").extend(noColor(), version("1.0.0"), help()).run(() => {
  console.log("Hello!");
});
```

## Behavior

- The extension injects a root `color` flag with default `true`
- The flag is inherited by subcommands
- The override applies to `@crustjs/style` default exports and built-in Crust extensions that use them

## Ordering

Register `noColor()` before extensions that may render output, such as `help()`.
