The plugins package provides official extensions for common CLI features. It depends on `@crustjs/core`.

## Install

```sh
bun add @crustjs/plugins
```

## Exports

### Extension Factories

| Export                                                      | Description                                              |
| ----------------------------------------------------------- | -------------------------------------------------------- |
| [`help()`](/docs/modules/plugins/help)                      | Adds `--help` / `-h` and auto-generates help text        |
| [`noColor()`](/docs/modules/plugins/no-color)               | Adds `--color` / `--no-color` runtime color control      |
| [`version()`](/docs/modules/plugins/version)                | Adds `--version` / `-v` to display version               |
| [`didYouMean()`](/docs/modules/plugins/did-you-mean)        | Suggests corrections for mistyped subcommands            |
| [`updateNotifier()`](/docs/modules/plugins/update-notifier) | Checks npm for newer versions and displays update notice |
| [`completion()`](/docs/modules/plugins/completion)          | Generates bash/zsh/fish tab-completion scripts           |

### Utilities

| Export                       | Description                         |
| ---------------------------- | ----------------------------------- |
| `renderHelp(command, path?)` | Generate help text programmatically |

### Types

| Type                           | Description                                       |
| ------------------------------ | ------------------------------------------------- |
| `VersionValue`                 | `string \| (() => string)` — version plugin input |
| `DidYouMeanPluginOptions`      | Options for the did-you-mean extension            |
| `UpdateNotifierPluginOptions`  | Options for the update notifier extension         |
| `UpdateNotifierCacheConfig`    | Cache configuration for update notifier           |
| `UpdateNotifierCacheAdapter`   | Cache adapter interface for update notifier       |
| `UpdateNotifierPackageManager` | Package manager union for update notifier         |
| `UpdateNotifierInstallScope`   | Install scope union for update notifier           |
| `CompletionPluginOptions`      | Options for the completion extension              |
| `CompletionShell`              | `"bash" \| "zsh" \| "fish"` shell union           |

Manual pages are provided by [`@crustjs/man`](/docs/modules/man) (build-time mdoc), not by this package.

## Usage

```ts
import { help, noColor, version, didYouMean, updateNotifier, completion } from "@crustjs/plugins";
import { Crust } from "@crustjs/core";

const main = new Crust("my-cli")
  .meta({ description: "My CLI" })
  .extend(
    noColor(),
    version("1.0.0"),
    didYouMean({ mode: "help" }),
    help(),
    updateNotifier({ packageName: "my-cli", currentVersion: "1.0.0" }),
    completion({ version: "1.0.0" }),
  )
  .run(() => {
    console.log("Hello!");
  });

await main.execute();
```

`noColor()` should be registered before extensions that may render output, such as `help()`, so `--color` and `--no-color` can affect their output.

## When to Use Directly

Use `@crustjs/plugins` directly when you're already importing from `@crustjs/core` and want to add official plugins without the `crust` CLI binary.

For most CLI applications, install both `@crustjs/core` and `@crustjs/plugins` as runtime dependencies.
