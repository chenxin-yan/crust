## Usage

<include lang="ts" meta='title="cli.ts"'>
  ../../../../examples/modules/extensions/version.ts
</include>

```sh
$ my-cli --version
my-cli v1.2.3
```

`version()` owns the root-only `--version` and `-v` flag. It prints to stdout instead of running the Command Action. Subcommands reject it: `my-cli deploy --version` is an unknown flag.

## API

```ts
version();
version("1.2.3");
version(() => process.env.APP_VERSION ?? "dev");
```

- Without an explicit value, `version()` requires root `version` metadata; omitting it is a type error. A value typed `string | undefined` still requires that metadata, as described by [`RootMetaKey`](/docs/api/types#rootmetakey).
- A function value is called when the flag is handled.
- An explicit value affects only the version flag. It does not set root metadata for completion, skills, or other Extensions.

```ts
version("1.2.3", { format: "plain" });
// $ my-cli --version
// 1.2.3
```
