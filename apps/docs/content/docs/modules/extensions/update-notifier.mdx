---
title: Update Notifier
description: Check npm for a newer stable version after a command succeeds.
---

## Usage

```ts
import { Crust } from "@crustjs/core";
import { updateNotifier } from "@crustjs/extensions";
import pkg from "../package.json";

const app = new Crust("my-cli")
  .extend(
    updateNotifier({
      packageName: pkg.name,
      currentVersion: pkg.version,
    }),
  )
  .action(({ stdout }) => stdout("Done"));

await app.execute();
```

## API

```ts
function updateNotifier(options: UpdateNotifierOptions): Extension;
```

/>

The `postRun` hook checks for an update only after a Command Action completes successfully. Network, registry, cache, and response failures are swallowed so the notifier does not fail a successful command. It does not check after `ctx.finish()` short-circuits such as `--help`. The notice is written through the invocation's stderr callback (process stderr under `execute()`). Version comparison follows SemVer precedence, so a stable release is considered newer than its prerelease.

By default, notifier state is persisted at `stateDir(packageName)` using `@crustjs/store`. A fresh cached result is reused for 24 hours and duplicate notices for the same version are suppressed across process invocations. Set `cache: false` to opt out, or provide a custom adapter to control persistence and `intervalMs`. By default, the notice reports only the available version. Set `installScope` to generate a package-manager-specific update command, provide `updateCommand` for a custom command, or set `updateDocsUrl` to link to update instructions. Automatic package-manager detection uses `npm_config_user_agent` when available. An `updateCommand` callback receives `undefined` for `installScope` unless the scope was explicitly configured.

## Cache

The built-in cache is enabled automatically; no setup is required:

```ts
updateNotifier({
  packageName: "my-cli",
  currentVersion: "1.2.3",
});
```

Disable all cache reads and writes when every invocation should check the registry:

```ts
updateNotifier({
  packageName: "my-cli",
  currentVersion: "1.2.3",
  cache: false,
});
```

For custom persistence, provide an adapter:

The adapter reads and writes this structural state shape; `UpdateNotifierState` itself is not exported from the package root:

<auto-type-table
  path="../../../../../../packages/extensions/src/update-notifier.ts"
  name="UpdateNotifierState"
/>

The package exports `UpdateNotifierCacheAdapter`, `UpdateNotifierCacheConfig`, `UpdateNotifierInstallScope`, and `UpdateNotifierPackageManager` alongside `UpdateNotifierOptions`.

```ts
import { updateNotifier, type UpdateNotifierCacheAdapter } from "@crustjs/extensions";

let state: Awaited<ReturnType<UpdateNotifierCacheAdapter["read"]>>;
const adapter: UpdateNotifierCacheAdapter = {
  read: async () => state,
  write: async (nextState) => {
    state = nextState;
  },
};

const notifier = updateNotifier({
  packageName: "my-cli",
  currentVersion: "1.2.3",
  cache: { adapter, intervalMs: 60 * 60 * 1000 },
});
```
