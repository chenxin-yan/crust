## Usage

<include lang="ts" meta='title="cli.ts"'>
  ../../../../examples/modules/extensions/help.ts
</include>

```sh
$ my-cli --help
my-cli - My CLI

Usage:
  my-cli [options]

Commands:
  deploy     Deploy the app

Options:
  -h, --help                   Show help
```

`help()` owns the recursive `--help` and `-h` flag, and shows help when the selected command has no Command Action.

## Behavior

- `--help` is an eager [handler](/docs/guide/extensions#write-your-own): it wins over every non-eager flag handler, such as `deploy --preview --help`. Between `--help` and `--version`, the flag given first wins.
- The no-action fallback runs only when no flag handler took over, so `my-cli --version` still prints the version on an action-less root.
- Subcommands are listed with their aliases, from `defineCommand()` metadata, without running their recipes: a command whose recipe throws still appears. Hidden commands stay routable but are not listed.
- A flag that takes a value shows its type after its spellings, such as `-p, --port <number>`; boolean flags show none. Choices, defaults, and env variables follow the description.
- A label too wide for its column widens the column, so descriptions stay aligned.

## Section consumer

```ts
const documentedApp = new Crust("my-cli", {
  sections: [{ title: "Example", body: "my-cli deploy", only: [help] }],
});
```

Pass `help` in a section's `only` or `except` list to include or exclude that section from help output. See [section consumers](/docs/guide/extensions#section-consumers).

## `renderHelp`

```ts
const text = await renderHelp(await app.snapshot());
// => "my-cli - My CLI\n\nUsage:\n  my-cli [options] ..."
```

`renderHelp(command, path?)` renders a Command Snapshot without running the app and resolves to the help text. `path` is the command path shown in the output and defaults to `[meta.name]`.
