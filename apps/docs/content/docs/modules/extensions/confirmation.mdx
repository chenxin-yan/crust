## Usage

<include lang="ts" meta='title="cli.ts"'>
  ../../../../examples/modules/extensions/confirmation.ts
</include>

```sh
$ my-cli drop --yes
Dropped
```

`confirmation()` adds a recursive boolean `--yes` flag. `ConfirmationRequiredError` is exported for commands that need confirmation without `--yes`; its message names the command and `--yes`.

## Limitations

Extension flags are either recursive or root-only, so `--yes` is accepted by every command. A command cannot declare its own `yes` flag while `confirmation()` is registered.
