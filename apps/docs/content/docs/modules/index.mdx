title: "Overview"
description: Crust packages for authoring, distributing, and supporting CLI applications.
---

Install [`@crustjs/core`](/docs/modules/core) and the capabilities your application needs. The framework spine packages share one lockstep version.

## Framework spine

| Module                                                       | Description                                                                           |
| ------------------------------------------------------------ | ------------------------------------------------------------------------------------- |
| [`@crustjs/core`](/docs/modules/core)                        | Command definitions, Contexts, Extensions, execution, and errors                      |
| [`@crustjs/extensions`](/docs/modules/extensions)            | Official Extensions: help, version, completion, typo presentation, color, and updates |
| [`@crustjs/crust`](/docs/modules/crust)                      | Build and distribution CLI                                                            |
| [`create-crust`](https://www.npmjs.com/package/create-crust) | Generate the minimal Crust starter                                                    |
| [`@crustjs/man`](/docs/modules/man)                          | Generate mdoc(7) manual pages from Command Snapshots                                  |
| [`@crustjs/skills`](/docs/modules/skills)                    | Generate agent skills from Command Snapshots                                          |

## Standalone libraries

| Module                                        | Description                                     |
| --------------------------------------------- | ----------------------------------------------- |
| [`@crustjs/create`](/docs/modules/create)     | Headless scaffolding engine for create-\* tools |
| [`@crustjs/progress`](/docs/modules/progress) | Non-interactive progress indicators             |
| [`@crustjs/prompts`](/docs/modules/prompts)   | Interactive terminal prompts                    |
| [`@crustjs/store`](/docs/modules/store)       | Typed configuration persistence                 |
| [`@crustjs/style`](/docs/modules/style)       | Terminal styling and layout utilities           |
