## Scaffold a project

```sh
bun create crust my-cli
cd my-cli
bun install
```

`create-crust` generates one minimal TypeScript template. Choose a distribution mode when prompted: a compiled binary or a Bun runtime package. To organize a larger application, follow [Split Commands Across Files](/docs/guide/split-files).

## Install manually

```sh
bun add @crustjs/core @crustjs/extensions
bun add -d @crustjs/crust
```

```ts title="src/cli.ts"
import { Crust } from "@crustjs/core";
import { help } from "@crustjs/extensions";

const app = new Crust("my-cli").extend(help()).handle(({ stdout }) => stdout("Hello"));

await app.execute();
```

Add scripts:

```json title="package.json"
{
  "scripts": {
    "dev": "bun run src/cli.ts",
    "build": "crust build"
  }
}
```

## Packages

| Package               | Purpose                                                                      |
| --------------------- | ---------------------------------------------------------------------------- |
| `@crustjs/core`       | Commands, Contexts, Extensions, schemas, errors, and Command Snapshots       |
| `@crustjs/extensions` | Official help, version, completion, suggestion, color, and update Extensions |
| `@crustjs/crust`      | Build, package, and publish CLI                                              |
| `@crustjs/prompts`    | Interactive prompts                                                          |
| `@crustjs/progress`   | Spinners and progress output                                                 |
| `@crustjs/style`      | Terminal styling                                                             |
| `@crustjs/store`      | Persistent storage                                                           |
| `@crustjs/man`        | Manual-page generation                                                       |
| `@crustjs/skills`     | Agent skill generation                                                       |

Bun is the supported runtime and package manager. All packages are ESM and TypeScript-first.

Upgrading from 0.1? Read [Migrate to 0.2](/docs/guide/migrate-to-0-2).
