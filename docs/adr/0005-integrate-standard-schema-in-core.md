# Integrate Standard Schema in Core

Argument and flag definitions may carry a Standard Schema directly, and the inferred schema output reaches the Command Handler without an `arg()`, `flag()`, or `commandValidator()` wrapper. Core supports either its existing lightweight built-in value definitions or schema-backed definitions. In schema mode, positional arguments receive raw strings, while flags use `type: "string" | "boolean"` solely to declare token consumption and receive the corresponding raw value. Core supplies syntax metadata while the schema exclusively owns coercion, defaults, requiredness, choices, and validation; Core value options cannot be mixed into that mode. Command-level schema integration moves into Core and `@crustjs/validate` is removed rather than retained as command wrappers or generic helpers users' schema libraries already provide. This favors one definition pipeline and first-class schema DX over preserving a separate validation layer or compatibility shim.
