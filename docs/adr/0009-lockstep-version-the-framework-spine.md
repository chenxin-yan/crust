# Lockstep-version the framework spine

`@crustjs/core`, `@crustjs/extensions`, `@crustjs/crust`, `create-crust`, `@crustjs/man`, and `@crustjs/skills` form a changesets `fixed` group and always publish the same version, starting at `0.2.0` (the lowest number above the group's highest published version, `@crustjs/man`/`@crustjs/skills` at `0.1.2`). Compatibility across the spine is answered by the version number itself instead of a matrix. Standalone libraries (`style`, `store`, `prompts`, `progress`, `create`, `utils`) keep independent versions because they are useful outside the framework and should not churn releases when core moves. Effect's model (fully independent versions with changesets internal-dependency bumps) was considered and rejected for the spine because man/skills/extensions consume core internals and must move together anyway.
