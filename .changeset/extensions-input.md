Add `input()`, an Extension with a recursive `--input` flag that accepts a command's arguments and flags as one JSON object keyed by their names (plus `raw` for passthrough values), the same shape MCP tools take. The value is inline JSON, `@path` to read a file, or `-` to read stdin (stdin something else already read to the end reads as empty). Arguments and flags given on argv win over the same keys; every other key replaces the environment value or default, converted as typed `run()` input. `--input` is bound in `setup`, so every `preRun` check sees its values whatever the `.extend()` order; it is also read when `--help` or another flag handler takes over. Invalid JSON, a non-object, an unreadable file, or a command whose argument and flag share a name (or one is named `raw`) fails with a `PARSE` error whose message starts with `--input:`; an invalid value, such as a bad URL, fails with the same `PARSE` error as argv. `input()` also adds a "JSON input" section to the root command's documentation (help, man page, and skills) describing this contract.
