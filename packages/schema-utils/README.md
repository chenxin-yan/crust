# @crustjs/schema-utils

> ⚠️ **Internal Crust workspace package.** Published to npm only so that
> [`@crustjs/validate`](https://www.npmjs.com/package/@crustjs/validate)'s
> `dependencies` resolve. Do not depend on this package directly — its
> surface is **not part of the public Crust API** and may change in any
> release without a deprecation cycle.

If you are looking for Standard Schema validation in a Crust CLI, use
[`@crustjs/validate`](https://www.npmjs.com/package/@crustjs/validate).
