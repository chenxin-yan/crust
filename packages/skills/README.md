# @crustjs/skills

Agent skill generation from Crust command definitions

## Install

```sh
bun add @crustjs/skills
```

## Documentation

Full docs: [crustjs.com/docs/modules/skills](https://crustjs.com/docs/modules/skills)

Skill names are used directly and validated against the Agent Skills specification. Use the exported `isValidSkillName()` helper when validating names before generation.
