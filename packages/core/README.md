# @crustjs/core

Core library for the Crust CLI framework.

Typed `run(path, { args, flags, raw })` binds structured values directly to the selected command; only the path selects subcommands. JSON values pass through unchanged. Use `execute({ argv })` for terminal argument parsing.

## Install

```sh
bun add @crustjs/core
```

Full docs: [crustjs.com/docs/modules/core](https://crustjs.com/docs/modules/core)
